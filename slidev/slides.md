# Khái Niệm Góc Lượng Giác

Góc lượng giác: Tia Om quay từ Ou đến Ov

Số đo góc: sd (Ou, Ov) = sd (Ou, Ow) - sd (Ov, Ow) + k.360

Hệ thức Chasles: sd (Ou, Ov) + sd (Ov, Ow) = sd (Ou, Ow) + k.360

Đơn vị đo: 1° = (π/180) rad, 1 rad = (180/π)°

Đường tròn lượng giác: Tâm tại gốc tọa độ, bán kính 1

# Quan hệ giữa các giá trị lượng giác

<div v-click>

- Công thức lượng giác cơ bản: sin²x + cos²x = 1
- Hằng đẳng thức: 1/cos²x = 1 + tan²x
- Quan hệ giữa sin, cos, tan, cot: tanx.cotx = 1
- Công thức liên quan: sin⁴x + cos⁴x = 1 − 2sin²x cos²x

# Giá trị lượng giác của góc đặc biệt

<div v-click>

- Cung đối nhau: Â và −Â, cos(−Â) = cosÂ, sin(−Â) = −sinÂ
- Cung bù nhau: Â và Ñ−Â, cos(Ñ−Â) = −cosÂ, sin(Ñ−Â) = sinÂ
- Cung hơn kém: Â và (Â+Ñ), cos(Â+Ñ) = −cosÂ, sin(Â+Ñ) = −sinÂ
- Cung phụ nhau: Â và Ñ−Â, cos(Ñ−Â) = sinÂ, sin(Ñ−Â) = cosÂ
