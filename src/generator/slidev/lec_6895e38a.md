::title::
<h1 style="color: #000;">3.1. Data Augmentation Strategies</h1>

::left::
- Data augmentation is crucial for reducing overfitting in large CNNs with 1.2 million training examples.
- We use two forms of data augmentation: random image translations & horizontal reflections (2048x larger dataset) and PCA-based color jittering.
- For translations, we extract random 224×224 patches from 256×256 images and their horizontal reflections, increasing training set size by 2048x.

::right::
- For color augmentation, we perform PCA on RGB pixel values and add multiples of principal components with magnitudes proportional to eigenvalues times Gaussian noise (σ=0.1).
- This scheme captures illumination invariance and reduces top-1 error rate by over 1%.

---
<h1 style="color: #000;">3.2. Regularization Methods for Overfitting Reduction</h1>

- Regularization methods are critical for reducing overfitting in deep CNNs with 60 million parameters.
- We used dropout in the first two fully-connected layers, which forces neurons to learn robust features by randomly ignoring half of them during training.
- Without dropout, our network showed significant overfitting, and training time roughly doubled.
- Dropout approximates averaging predictions from exponentially many sub-networks, improving generalization at test time.

::title::
<h1 style="color: #000;">4. Results and Evaluation</h1>

::left::
- Data augmentation strategies significantly expand training set size through random translations, reflections, and PCA-based intensity variations
- Our network uses 2048x larger training set via patch extraction and 10x prediction averaging at test time to reduce overfitting
- PCA-based color jittering alters RGB intensities by adding multiples of principal components with Gaussian noise (std=0.1) to simulate illumination changes

::right::
- Dropout technique randomly zeros 50% of hidden neurons during training to prevent co-adaptation and improve generalization
- Combining predictions from 7 CNNs achieves 15.3% top-5 error rate, outperforming previous state-of-the-art methods
